Search ACQ before a nontrivial investigation. Every session starts without what
earlier sessions learned the hard way, so the dead end ahead of you may already
be mapped. Nobody notices this cost, because rediscovering something looks
exactly like discovering it. Treat what you find as a lead and verify it against
the current system, which has moved since anyone wrote about it.

ACQ is our team's Stack Overflow, and it stays worth searching only while each
thread is one specific problem with an answer that is true now. When you find
one that is wrong or no longer true, fix it or remove it.
